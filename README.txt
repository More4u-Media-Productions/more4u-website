MORE4U PRODUCTIONS WEBSITE

This is a static GitHub-ready website.

Files:
- index.html
- projects.html
- blog.html
- styles.css
- scripts.js
- assets/ (put your actual logo/icon PNG files here)

IMPORTANT:
The image files referenced by the HTML are placeholders in this package because the actual image files were not included in the conversation. Add these files to assets/:
- more4u-logo.png
- more4u-logo-transparent.png
- more4u-logo-footer.png
- echo-icon.png
- dayline-icon.png

To run locally:
1. Put the files in a folder.
2. Add your images to assets/.
3. Open index.html in a browser.

To publish with GitHub Pages:
1. Create a GitHub repository.
2. Upload all files and the assets folder.
3. Enable GitHub Pages from the repository settings.
4. Choose the branch/folder containing index.html.

To add a blog post:
Open blog.html and copy one of the <article class="post"> blocks in the posts section.
